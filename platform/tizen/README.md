# Samsung Tizen adapter

Generación: `dart run tool/build.dart --target=tizen`

Se genera `dist/tizen/` con el payload Flutter Web del núcleo único. Ese payload debe empaquetarse como Web App usando las herramientas oficiales de Tizen. No se presenta como APK ni como soporte Flutter nativo.

Comparte M3U, EPG, HLS, recuperación, salud de fuentes, circuit breaker y catálogo con Android.
