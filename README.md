# reproductor-IPTV\n\nBase Flutter independiente para un reproductor IPTV resiliente.\n\nImplementado en esta primera fase: dominio separado de fuentes, parser M3U con límites, validación, estados de reproducción con protección contra eventos obsoletos, recuperación escalonada, circuit breaker, redacción de secretos y pruebas.\n\nNo genera ni modifica las listas IPTV existentes.\n\nSiguiente capa: adaptadores de playback por plataforma, monitor real de playhead/buffer, persistencia transaccional, XMLTV, failover operativo y UI TV/mobile.\n
